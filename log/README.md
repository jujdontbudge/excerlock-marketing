# Decision evidence

`log/events.jsonl` preserves attributable events. This is history, not another rulebook; current policy is routed through `AGENTS.md` and its canonical targets.

Read the tools in `tools/decision-log/README.md`. Full timelines are generated on demand into ignored `log/views/` by `tools/decision-log/declog.py render`; older views are retained there as `legacy-LOG.md` / `legacy-LOG-all.md`. Source transcripts and watcher state remain in their original ignored homes.
