# Liked slideshows corpus (analyses only)

Taste board for on-image caption voice. The corpus is **12 liked TikTok photo
posts** from the target audience account's Liked tab, **54 slides** total,
captured **2026-09-16**. Public counters on those posts are single-capture
observations, not proof that a caption style converts.

Slide images and the OCR transcript stay private and are **not committed**
here. These files keep only the written analyses and a post index.
