# Sections, core and accounts are separate modules with one-way references

The repo is split into `sections/` (one kind of marketing work each), `core/` (skills and workflows every section can use), `accounts/` (who each TikTok account's character is) and `library/`/`research/`. References only point downward: a section may use core, accounts, library and research; core never names a section or an account; sections never name each other. We chose this over one flat `skills/` folder because universal guides kept absorbing one account's details (another account's character inherited Zoey's leopard phone case), and because the captain plans to add AI UGC, real UGC, clipping and influencer sections that must be addable and removable without touching slideshows. `scripts/lint` enforces the reference rules.
