# ExcerLock Marketing

Marketing research and creative-production workspace at `/Users/johansardar/excerlockmarketing`.

This repository exists to research audiences and channels, develop marketing strategy, and produce creative assets and campaigns for ExcerLock. It is not the ExcerLock app codebase or a software-delivery workspace. Marketing work here is organized around evidence, creative quality, truthful claims, platform rules, publishing approval, and measurable campaign results.

Start Pi with:

```bash
pi-marketing
```

## Active capabilities

-   Public-web extraction and bounded crawling
    
-   Reddit, TikTok, Instagram, and YouTube research
    
-   Meta Ads Library and TikTok ad-library research
    
-   Video download, transcription, clipping, and creative analysis
    
-   Still-image prompting for TikTok slideshows as validated JSON (`skills/organic-json-image-prompting.md`, `scripts/image-prompt.py`, saved styles in `content/styles/`)
    
-   Guarded fal.ai generation for Seedance, Kling, OmniHuman, and WAN video models
    
-   Project-local Mem0 memory
    

## Main paths

-   `AGENTS.md` — operating method and tool routing
    
-   `BROWSER.md` — dedicated browser usage
    
-   `skills/` — specialized workflows
    
-   `scripts/` — active wrappers
    
-   `integrations/` — custom deep crawler and Mem0
    
-   `research/`, `content/`, `campaigns/`, `analytics/`, `experiments/`, `assets/` — outputs
    
-   `raw/` — temporary collected evidence and media
    

The app repository is separate from this marketing workspace.
