# Organic iPhone photo — superseded

This prose meta-prompt template was retired on 2026-09-22. Every image prompt is now JSON and
follows `skills/organic-json-image-prompting.md`, validated by `scripts/image-prompt.py check`.

What carried over:
- the polish-level table (polished, plandid, raw, jagged): section 6 of the book
- iPhone optics and processing realism, and the list of looks an iPhone never produces: sections 6 and 7
- "style, never identity": the reference manifest's `must_not_transfer`

What was dropped:
- the prose `full_prompt_string` output, which does not count as JSON
- the blanket "no readable brand logos" exclusion; the current rule is to keep natural branding

Original sources, kept for history: https://x.com/EXM7777/status/2095149262766301553 (format) and
https://x.com/EXM7777/status/2094848009477685681 (style cloning). The full old template is in git history.
