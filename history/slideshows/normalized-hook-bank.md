# Hook bank

The captain's ExcerLock hook ideas, grouped by hook type, ingested from his Google Doc worksheet on 2026-09-16 with spelling normalised. This file is the only copy. What each hook type means: `sections/slideshows/skills/hooks-and-formats/hooks.md`.

## How to read the tables

- **Hook** — cleaned text; `(unfinished)` marks fragments the author left incomplete.
- **Lane** — `gym` = gym-girl audience, `walking` = walking-girl audience, `both` = works for both, following the audience split in `research/video-analysis-595/report.md` §9 (9a gym girls, 9c walking girls).
- **ExcerLock mechanism** — the unlock condition the hook implies: gym arrival/stay/time, step target, walking duration, active walking — or `none stated`.
